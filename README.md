## 🌿 서비스 소개

여행을 떠날 때마다 **“우리 아이와 여기도 함께 갈 수 있을까?”**를 하나하나 확인해야 하는 반려인의 고민에서 **댕제주(DANGJEJU)**는 시작되었습니다.

댕제주는 사랑하는 반려견을 두고 떠나는 여행이 아니라, **함께 걷고 머물며 제주를 즐길 수 있도록 돕는 반려동물 동반 여행 정보 서비스**입니다.

제주 지역의 관광지·카페·음식점·숙박·레포츠 등 반려견과 함께 방문할 수 있는 장소를 한곳에서 탐색하고, 한국관광공사의 관광·반려동물 동반여행 데이터를 바탕으로 실제 방문 전에 필요한 동반 조건을 확인할 수 있도록 구성했습니다.

---

## 💡 해결하고 싶은 문제

반려견과 함께 여행할 때는 일반 관광정보만으로는 부족합니다. 같은 반려동물 동반 장소라도 **견종·크기 제한, 목줄이나 이동장 등의 준비사항, 실내·실외 출입 가능 여부**가 서로 달라 여러 정보를 개별적으로 찾아야 합니다.

댕제주는 관광정보와 반려동물 동반정보를 한곳에 모으고, 정보가 충분하지 않은 장소는 **‘방문 전 확인 권장’**으로 안내하여 사용자가 정보의 상태까지 구분할 수 있도록 했습니다.

## ✨ 주요 기능

| 기능 | 설명 |
| --- | --- |
| 📍 **지역별 탐색** | 제주시·서귀포시·동부·서부 등 원하는 여행 지역을 선택해 장소를 탐색합니다. |
| 🗂️ **카테고리 검색** | 관광지·카페·음식점·숙박·쇼핑·레포츠·문화시설·축제/행사 등으로 장소를 구분합니다. |
| 🐾 **반려견 동반정보** | 동반 가능 여부, 크기 제한, 필수 착용·준비, 실내·실외 이용 조건을 확인합니다. |
| 🗺️ **지도 + 목록 연계** | 장소 목록과 지도를 함께 보며 위치와 여행 동선을 확인할 수 있습니다. |
| 🏷️ **정보 상태 안내** | ‘동반 정보 제공’, ‘방문 전 확인 권장’ 등의 상태를 통해 정보 확보 여부를 안내합니다. |
| ❤️ **로그인 & 찜** | Google 로그인 후 마음에 드는 장소를 저장하고 다시 확인할 수 있습니다. |
| 📱 **반응형 UI** | PC와 모바일 환경에 맞춰 장소 탐색과 지도 이용 화면을 제공합니다. |
| ⚡ **조회 최적화** | 동일 조건 결과 캐싱과 중복 요청 방지, 필요한 시점의 상세 조회로 Firestore 사용량을 줄입니다. |

## 🧭 서비스 이용 흐름

```text
댕제주 접속
   ↓
제주 여행 지역 선택
   ↓
장소 유형 선택
   ↓
장소 목록 · 지도 탐색
   ↓
반려견 동반정보 확인
   ↓
장소 상세정보 확인
   ↓
마음에 드는 장소 찜
   ↓
방문 전 동반 조건 최종 확인
```

상세정보에서는 특히 **동반 가능 여부 / 크기 제한 / 필수 착용·준비 / 실내 / 실외**를 중심으로 실제 방문 판단에 필요한 정보를 제공합니다.

## 🗃️ 데이터 활용

댕제주는 관광 장소의 기본정보와 반려동물 동반여행 상세정보를 결합하여 사용자에게 제공합니다.

주요 반려동물 정보에는 다음과 같은 내용이 포함됩니다.

- 동반 가능 동물 및 크기 조건
- 목줄·이동장 등 필수 준비사항
- 실내·실외 동반 가능 여부
- 반려동물 관련 시설 및 이용 조건
- 방문 전 확인이 필요한 주의사항

> 실제 시설의 운영 정책은 변경될 수 있으므로, 방문 전 해당 시설의 최신 이용 조건을 다시 확인하는 것을 권장합니다.

## 🤖 AI 활용

프로젝트의 **기획, UI/UX 개선, 개발, 데이터 연동 및 코드 검토 과정에서 생성형 AI를 개발 보조 도구로 활용**했습니다.

- Google AI Studio를 활용한 초기 UI/UX 프로토타입 제작 및 반응형 화면 개선
- ChatGPT를 활용한 React/TypeScript 코드 작성 및 오류 분석
- 한국관광공사 API 데이터 구조 분석
- Firebase/Firestore 연동 및 조회 구조 개선
- GitHub Pull Request 기반 기능 검토 및 개선
- 사용자에게 반려동물 정보가 쉽게 전달되도록 정보 구조와 문구 개선

> 현재 댕제주는 AI가 사용자에게 여행지를 자동 추천하는 서비스가 아니라, **서비스 개발 및 기획 과정에서 AI를 보조 도구로 활용한 프로젝트**입니다.

## 🚀 향후 계획

댕제주는 단순히 ‘반려견 동반 가능 장소’를 보여주는 것을 넘어, **반려견과 함께하는 제주 여행을 준비하는 과정 전체를 더 편리하게 만드는 서비스**를 목표로 합니다.

향후에는 반려견 크기·동반 조건 기반 맞춤 필터링, 사용자 위치를 활용한 주변 장소 탐색, 실제 방문자의 후기 및 정보 제보 기능, 반려동물 편의시설 정보 확대 등을 고려하고 있습니다. 장기적으로는 동물병원·반려동물 용품점 등까지 범위를 넓혀 **제주 반려동물 여행 통합 플랫폼**으로 발전시키는 것을 목표로 합니다.

## ▶️ 실행 방법

```bash
npm install
npm run dev
```

개발 서버는 기본적으로 `http://localhost:3000`에서 실행됩니다.
